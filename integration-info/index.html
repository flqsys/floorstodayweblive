Auto-resize listener add once per page · sizes all three embeds above 
<script>
// Resizes the iframe to match the form's real height, no scrollbar
window.addEventListener('message', function (e) {
  if (!e.data || !e.data.ftEmbedHeight) return;
  var idMap = { booking: 'ft-booking-embed', contact: 'ft-contact-embed', utm: 'ft-utm-embed' };
  var iframe = document.getElementById(idMap[e.data.ftEmbedType]);
  if (iframe) iframe.style.height = e.data.ftEmbedHeight + 'px';
});
</script>
Embeds render on floorstoday.ca and any of its subdomains. A domain outside that family won't be able to load them — ask for it to be added first.

Social tracking links

12 channels

Each link points at the same homepage but tags itself with a source. Post the Facebook link in Facebook, the Instagram link in your Instagram bio, and so on — when someone clicks through and submits a form, that lead shows up in the inbox already labeled with the real channel it came from, instead of every visit landing as generic “Direct” traffic. That's the difference between guessing which channel brings in leads and actually knowing it.

The tag is remembered for 24 hours after the click, so it still gets credited even if someone browses a few pages before filling out a form. Always copy the link from here rather than the plain homepage URL — the tracking only works because of the ?hello_social= part at the end.

Adding an embed in Elementor

  1. Drag an HTML widget onto the page — not the Text Editor widget, it strips <iframe> and <script> tags.
  2. Paste one embed snippet per widget.
  3. Add the auto-resize script in one more HTML widget anywhere on the page — only needed once, even with multiple embeds.
  4. Click Update, then check the result on the published page, not the editor canvas — Elementor's own preview frame can render iframes oddly even when the live page is correct.
